### 4. 端到端跑一条 G1 并解码下发指令

```bash
python3 klipper/klippy/klippy.py sim/host-sim.cfg -i sim/demo.gcode \
  -o sim/out-serial.log -d klipper/out/klipper.dict -l sim/klippy.log

cd klipper/klippy && python3 parsedump.py ../out/klipper.dict ../../sim/out-serial.log
```

`sim/demo.gcode`：

```
SET_KINEMATIC_POSITION X=0 Y=0 Z=0    ; 跳过 G28，直接给定已归位位置
G90
G1 X50 F3000
G1 X50 Y50 F6000
M400
```

下发结果节选（X 轴）：

```
config_stepper oid=2 step_pin=1 dir_pin=2 invert_step=0 step_pulse_ticks=40
queue_step oid=2 interval=5040825 count=1 add=0      # 起步
queue_step oid=2 interval=16230 count=4 add=-1525    # 加速
queue_step oid=2 interval=5000 count=917 add=0       # 匀速
queue_step oid=2 interval=5000 count=3002 add=0      # 第二次 flush 续传
queue_step oid=2 interval=5028 count=16 add=112      # 减速
```

整条链路一次性看到：`od=2` 的 stepper oid、`set_next_step_dir` 方向、`queue_step` 的
`interval/count/add` 三元组（批量压缩的证据）、以及全部时间都是 20 MHz 绝对时钟。

## 关键发现

1. **本版本路径与计划不一致**（详见 `docs/code-map.md`）：
   `lookahead.py`、`trapq.py` 已并入 `klippy/toolhead.py`；`gcode_move.py` 进 `klippy/extras/`；
   `chelper/` 进 `klippy/chelper/`；MCU 端 `src/stepgen.c` 改名 `src/stepper.c`；
   `docs/Motion_analysis.md` 不存在，改看 `docs/Kinematics.md`。
2. **没有 `config/simulator.cfg`**：只能自己编译 host simulator 拿 `out/klipper.dict`，
   再用批处理模式（`-i` + `-o`）跑，不需要真实串口。
3. **`[mcu]` 必须写 `serial`**，即使批处理根本不开串口；写个假的 `/dev/ttyACM0` 即可。
4. **host simulator 用数字引脚**（`step_pin: 1`），没有 `PA0` 之类的命名枚举。
5. **数值自洽**：`rotation_distance=40`、`microsteps=16` → 80 steps/mm；50 mm ⇒ 4000 步，
   与 `queue_step count` 累计完全吻合；50 mm/s ⇒ 4000 step/s ⇒ 20 MHz/4000 = 5000 tick，
   正是匀速段 `interval=5000`。
6. **一次 move 会被 flush 切成多段下发**：匀速段被拆成 `917 + 3002` 两批，
   说明下发粒度跟 klippy 的 flush 时机有关，后面学 stepcompress 流控时要回来看这个现象。

## 卡点与处理

| 卡点 | 处理 |
| ---- | ---- |
| `make` 报 `scripts/check-gcc.sh: Command not found` | Windows git 检出子模块为 CRLF，shebang 失效；子模块内改 `core.autocrlf=false` 并 `git rm --cached + reset --hard` 转 LF |
| `Multiple definitions for command 'identify'` | 忘了 `make olddefconfig`，配置项未展开 |
| `ModuleNotFoundError: greenlet` | `pip install --user -r klipper/scripts/klippy-requirements.txt`（无 `python3-venv`，未用 venv） |
| `Option 'serial' must be specified` | `[mcu]` 补 `serial: /dev/ttyACM0` |
| 配置里 `PA0` 一类引脚报 Unknown pin | 改用数字引脚 |
